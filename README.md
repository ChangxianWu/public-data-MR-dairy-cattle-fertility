# Public-data two-sample Mendelian randomization of dairy production and conformation traits on female fertility in US Holstein cattle

Code and published result tables for the manuscript *"Two-sample Mendelian randomization of dairy production and conformation traits on female fertility in US Holstein cattle: allele-strand verification and power-based bounds"* (under review).

The study asks whether the adverse genetic correlation between milk production and female fertility reflects direct causal effects, using **exclusively public summary statistics**: 253 instruments from 792 fine-mapped signals for 24 production and conformation traits (50,309 US Holstein bulls) tested against the IndexP60 fertility index (2,448 US Holstein cows). Every result table shipped in `results/` can be regenerated byte-for-byte from the public raw data.

## Why this pipeline exists

Three things make cross-dataset livestock MR error-prone, and this repository implements the safeguards as code:

1. **Cross-build alignment** — the exposure and outcome statistics use different genome builds (ARS-UCD1.2 vs UMD3.1.1); `code/liftover_chain.py` is a zero-dependency UCSC chain lifter validated at 99.8% (499/500) against `pyliftover`.
2. **Per-SNP allele-strand verification** — 280 of 570 (49%) verifiable lead SNPs required orientation flipping between the two datasets; the flip is invisible to allele-frequency matching. Every orientation decision is recorded in `results/allele_strand_audit_table_2026-09-15.tsv`.
3. **Honest power accounting** — at 80% power the design excludes effects of >= 0.029 pregnancy-probability points per exposure point (MDES columns in the main results table).

`code/strand_flip_simulation.py` additionally provides a 72-cell Monte-Carlo grid quantifying what uncorrected flips do to an inverse-variance-weighted analysis: independent flips collapse power (5-9% left at the observed flip rate) and manufacture false heterogeneity, whereas trait-clustered flips preserve significance while reversing the direction of true effects (39% wrong-direction significant findings at the empirical rate). The random source is a SHA-256 counter stream with a fixed seed (20261023), so every number is exactly reproducible.

## Repository structure

```
code/
  run_mr_main.py              core MR pipeline: regenerates the five main tables from the raw data
  make_umd_bed.py             EMMAX CSV -> UMD3.1.1 BED (byte-verified against the original analysis)
  liftover_chain.py           zero-dependency UCSC chain liftover (build_index / convert)
  dryad_download.py           Dryad downloader with automatic Anubis proof-of-work handling
  dryad_resume.py             ranged resume for large Dryad files
  kiz_download.py             CattleGTEx portal downloader (optional, for the Figure 6 context)
  kiz_resume2.py              ranged resume for the portal
  make_tables.py              regenerates the journal tables (tables/) from results/
  make_figures.py             regenerates Figures 1-7 (figures/, 300 dpi PNG)
  strand_flip_simulation.py   72-cell Monte-Carlo grid on uncorrected strand flips
  verify_results.py           checks reproduced tables against results/CHECKSUMS.txt
data/
  derived/                    UCSC bosTau6->bosTau9 chain (3.1 MB) used by the liftover step
  raw/                        empty - put the Dryad downloads here (see below)
results/                      the published result tables (English filenames) + CHECKSUMS.txt
figures/                      Figures 1-7 as used in the manuscript (PNG)
supplementary/                full simulation grid + SHA-256 manifest of the raw-data snapshots
tables/                       journal tables (generated by code/make_tables.py)
```

Some inline comments in the auxiliary scripts (downloaders, chain parser) are in Chinese; all interfaces, filenames, console output of the core pipeline and results are in English.

## Data sources (all public; not included in this repository)

| # | Role | File(s) to place in `data/raw/` | Source | Size |
|---|---|---|---|---|
| 1 | Exposure fine-mapping summary statistics (30 dairy traits; 792 signals; ARS-UCD1.2) | `vmcvdnd3q__finemapping_summary_stats_dairy_2025.csv`, `vmcvdnd3q__Supplemental_Tables.xlsx` | Dryad doi:10.5061/dryad.vmcvdnd3q | ~106 MB + xlsx |
| 2 | Outcome fertility GWAS (IndexP60; UMD3.1.1) | `0gb5mkm04__File_S1_EMMAX_RI_extracted.csv` | Dryad doi:10.5061/dryad.0gb5mkm04 | ~547 MB |
| 3 | Mammary cis-eQTL (optional, Figure 6 context) | `Mammary_Gland.tar.gz` | CattleGTEx portal, https://cattlegtex.kiz.ac.cn | ~1 GB |

No large files are shipped: the lifted-over outcome BED that the pipeline consumes is regenerated from source #2 in three scripted steps (below). The UCSC `bosTau6ToBosTau9.over.chain.gz` used for the lift is included in `data/derived/` (3.1 MB) so the conversion is exactly reproducible; the BED-generation and liftover steps were verified byte-identical to the original analysis (599,429 probes lifted, 12,317 unmapped = 98.0%). The SHA-256 of the raw snapshots used for the published results is recorded in `supplementary/data_manifest.json`.

Dryad applies an Anubis proof-of-work challenge to scripted downloads; `code/dryad_download.py` solves it automatically:

```
python code/dryad_download.py vmcvdnd3q                  # list file ids of the dataset
python code/dryad_download.py vmcvdnd3q <file_id> data/raw/<output_name>
python code/dryad_resume.py    <url> data/raw/<output_name>   # ranged resume for large files
```

Downloading the two Dryad files with a browser into `data/raw/` works just as well.

## Reproduction

Requirements: Python 3.13 (3.11+ works), then

```
pip install -r requirements.txt
```

| Step | Command | Wall time | Output |
|---|---|---|---|
| 1. put raw data in place | see table above | - | `data/raw/*.csv`, `*.xlsx` |
| 2. EMMAX CSV -> BED | `python code/make_umd_bed.py data/raw/0gb5mkm04__File_S1_EMMAX_RI_extracted.csv data/derived/emmax_umd31.bed` | ~2 min | UMD3.1.1 BED |
| 3. liftover to ARS-UCD1.2 | `python code/liftover_chain.py build_index data/derived/bosTau6ToBosTau9.over.chain.gz data/derived/chain_index.pkl` then `python code/liftover_chain.py convert data/derived/chain_index.pkl data/derived/emmax_umd31.bed data/derived/emmax_arsucd12.bed data/derived/unmapped.bed` | ~15 min | analysis BED (599,429 lifted) |
| 4. core MR pipeline | `python code/run_mr_main.py --datadir data/raw` | ~7 min | five tables in `results/` |
| 5. verify against published tables | `python code/verify_results.py` | < 1 min | `ALL CHECKSUMS MATCH` |
| 6. journal tables | `python code/make_tables.py` | < 1 min | `tables/` |
| 7. figures | `python code/make_figures.py` | < 1 min | `figures/` |
| 8. strand-flip simulation | `python code/strand_flip_simulation.py` | ~1 min | `supplementary/strand_flip_simulation_S17_2026-10-23.tsv` |

Figure 6 additionally reads the CattleGTEx mammary cis-eQTL download (`code/kiz_download.py`); without it the script skips Figure 6 and regenerates Figures 1-5 and 7.

Step 3 recomputes the SHA-256 of every reproduced table and compares it with `results/CHECKSUMS.txt`, which records the hashes of the tables shipped with the manuscript. A mismatch means your raw snapshots differ from the ones used for the published results (check `supplementary/data_manifest.json`).

Notes:

- The main pipeline was run with Python 3.13 and depends on `scipy` (normal CDF), `openpyxl` (supplemental xlsx) and the standard library; figures need `matplotlib`.
- The strand-flip simulation is seeded (SHA-256 counter stream, seed 20261023) and aborts unless its calibration cells reproduce nominal type-I error (0.04-0.06) and power (0.76-0.84).
- Figure 6 (mammary cis-eQTL proximity) uses the optional CattleGTEx download; the proximity counts are reported in the manuscript and do not enter the main results.
- The authors' internal 19-point consistency gate (manuscript-package agreement) ships with the journal submission package; `code/verify_results.py` is the public-repo equivalent for table-level verification.

## Key results (all regenerated by this pipeline)

- 280/570 (49%) verifiable lead SNPs required strand flipping; 10/24 trait estimates changed sign pre- vs post-audit.
- No association survived Benjamini-Hochberg correction across 24 exposures (minimum q = 0.074); four conformation traits (three udder/teat, one body conformation) showed nominal, direction-stable, hypothesis-generating associations.
- MDES at 80% power: 0.029 predicted-pregnancy-probability points per exposure point.
- Strand-flip simulation: at the empirical flip rate, unaudited analyses agree with the audited direction only at chance level; trait-clustered flips preserve significance while reversing true directions (39% wrong-direction findings).
